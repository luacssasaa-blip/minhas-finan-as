# Minhas Finanças

Aplicativo web responsivo para organizar receitas, despesas, categorias e dívidas.

## Executar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Os dados desta primeira versão são salvos localmente no navegador. A integração com Supabase pode ser configurada em uma etapa posterior usando `.env.example`.
